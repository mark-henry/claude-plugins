# Parked from adversarial:toolkit

Red-flag tables and notes about the skill itself, moved out of the body of `adversarial:toolkit` and kept here until the pack's restructuring decides what stays. Nothing in the skill depends on this file.

## Red flags

Scan this mid-task. Each thought on the left means stop. Add rows from rationalisations you actually see, verbatim, with the reality that answers them.

| Thought | Reality |
|---|---|
| "This is simple, skip the reviewer." | Depth comes from consequence, not size. The check rung always runs; the rest is bought by what a wrong answer costs. |
| "I read my own diff carefully." | Same author, same blind spots. A mental self-review does not count. |
| "The reviewer will just find something new." | Bound the loop instead: minor findings never earn another round. Skipping the reviewer is not the fix. |
| "This finding is obviously wrong, I'll drop it." | Adjudicate on the record or send it to a validator. A silent discard is forbidden. |
| "The fix was small, skip the re-check." | The pass that fixed findings cannot certify the result. Run a scoped re-check. |
| "The worker ran its own review, free assurance." | A worker's self-spawned reviewer is a defect. The orchestrator allocates every seat. |
| "The null shows the safeguard is unneeded." | A null on an eval that never contains the hazard is no evidence. |
| "The judges agreed, so it is right." | Agreement orders attention. Same-family agreement is one datum; a vote measures agreement, not correctness. |
| "The hand-back says done." | A hand-back is a claim. Inspect the working tree, run the command, read the output. |
| "I'll tell the reviewer to skip style so it focuses." | Never tell a reviewer what not to flag. Scope by what to look for. |
| "I'll give the proposers my candidate list to save time." | Candidate lists anchor proposers and their labels leak into answers. |
| "The chain's last version is the improved one." | A bare chain's last version wins by position. End in a blind pick that includes the original. |
| "A vote will settle this factual question." | Check it. A confident wrong answer can win unanimously. |
| "No findings looks thin; I'll add something." | "No findings" is a complete result. |
| "The scorer passed everything, so the items are good." | A check you never saw fire is unproven. Plant a positive. |
| "I'll show the expert my verdicts to save their time." | An agent's verdict shown first anchors the human it was meant to check. Keep mum until the labels are in. |
| "One more round and it'll be clean." | Every loop has a cap. At the cap, escalate; never approve by exhaustion. |
| "The citation is probably right." | "Could not verify" is never counted as supported. |
| "I'll re-judge until the verdict makes sense." | Never re-judge until a verdict suits. Re-judge a claimed win blind, once, before reporting. |
| "I'll mention my hunch so the checker knows where to look." | An agent given a conclusion tends to return it confirmed. Facts, not your diagnosis. |
| "Let the judge combine the best parts." | The judge then grades its own combination. Judges pick; a separate agent grafts. |
| "It should pass now." / "Probably fixed." | Hedged language before verification. Run it, read the full output, then claim. |
| "Fresh context is fresh enough; I'll reuse this agent for the second opinion." | A reused context is one sample, not a second opinion. |
| "Couldn't verify it, but it's probably fine." | Unverifiable is its own list; never counted as supported. |
| "The checker could not disprove it." | Unresolved, not confirmed. |
| "We used more tokens, so this was better." | Compare cost per accepted result against the bare and matched-budget arms. |
| "The final version must be best." | Position is not selection. Let the original and the sealed default win. |
| "I agreed with the owner immediately, so the framing is settled." | Fast agreement is a reason to seek disconfirming evidence, not evidence for the framing. |
